# JavaScript Functions Web App

This is a **web application** built with **JavaScript** and **Tailwind CSS** that allows users to test various functions interactively. The app includes functions for string manipulation, array operations, and mathematical calculations.

---

## Features

### **String Manipulation**
1. **Reverse a String**: Reverses a given string.
2. **Count Characters**: Counts the number of characters in a string.
3. **Capitalize Words**: Capitalizes the first letter of each word in a sentence.

### **Array Functions**
1. **Find Maximum**: Finds the maximum value in an array of numbers.
2. **Find Minimum**: Finds the minimum value in an array of numbers.
3. **Sum of Array**: Calculates the sum of all elements in an array.

### **Mathematical Functions**
1. **Factorial**: Calculates the factorial of a given number.
2. **Prime Number Check**: Checks if a number is prime.
3. **Fibonacci Sequence**: Generates the Fibonacci sequence up to a given number of terms.

---

## Technologies Used

- **HTML5**: For structuring the web page.
- **Tailwind CSS**: For styling the web app.
- **JavaScript**: For implementing the functions and interactivity.
